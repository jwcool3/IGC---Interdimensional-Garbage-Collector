# 🏭 Crafting Economy Design - Strategic Resource Separation

## 🎯 **Economic Layers Strategy**

### **Layer 1: Raw Resources** = Direct consumption for simple needs
### **Layer 2: Crafted Components** = Manufactured items requiring recipes/facilities  
### **Layer 3: Abstract Currencies** = Meta-progression and advanced systems

---

## 🔩 **RAW RESOURCES - Direct Use Only**

### **What Uses Raw Resources Directly:**
```
⚡ Facility Operations:
├── Facility Energy Costs (Plastic for fuel, Crystals for power)
├── Basic Maintenance (Metal Scraps for repairs)
├── Emergency Repairs (any suitable materials)
└── Contamination Cleanup (Chemical compounds)

🔬 Research Materials:
├── Basic Research (Organic Matter for bio-studies)
├── Sample Analysis (various materials for testing)
├── Experimental Protocols (mixed resource consumption)
└── Data Collection (Electronics for sensors)

💊 Consumables:
├── Probe Fuel (Plastic → converted to fuel)
├── Life Support (Organic Matter → air/food)
├── Decontamination Supplies (Chemical compounds)
└── Emergency Rations (processed Organic Matter)

🎁 Small Convenience Items:
├── Storage Containers (15 Plastic + 5 Metal Scraps)
├── Basic Tools (20 Metal Scraps + 10 Electronics)
├── Safety Gear (25 Organic Matter + 15 Plastic)
└── Probe Repair Kits (30 Mixed Resources)
```

## ⚖️ **Strategic Balance Points**

### **Resource Pressure Points:**
1. **Early Game**: Raw resources are precious, no crafting yet
2. **Mid Game**: Tension between using raw resources vs saving for crafting
3. **Late Game**: Crafted components become the bottleneck

### **Player Choices:**
1. **Immediate gratification**: Use raw resources directly for quick gains
2. **Long-term investment**: Save resources for powerful crafted components
3. **Knowledge path**: Convert to RP/DP for permanent improvements

### **Economic Flow:**
```
Waste Collection → Raw Resources → Either:
├── Direct Use (immediate small benefits)
├── Crafting (delayed large benefits)
├── Convert to RP (operational improvements)
└── Convert to DP (dimensional advancement)
```

This design ensures each economic layer has clear, distinct purposes while creating meaningful player choices! 🎯
